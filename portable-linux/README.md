# HojaSQL Studio portable para Linux

Modo portable:

- ejecuta `./abrir_consola_excel_portable.sh`
- o abre `HojaSQLStudio.desktop`
- si vas a distribuirlo en Linux, prefiere el `.tar.gz` porque conserva permisos ejecutables

Instalacion local en el launcher del usuario:

- ejecuta `./install_local.sh`
- luego puedes abrir la app desde el menu o con `hojasql-studio`

Para desinstalar:

- ejecuta `./uninstall_local.sh`

La carpeta portable debe contener:

```text
HojaSQLStudio/
abrir_consola_excel_portable.sh
HojaSQLStudio.desktop
hojasql.png
install_local.sh
uninstall_local.sh
README.md
```
